# 08. Al-Jadd wal-Ikhwah

**Cakupan**: kakek shahih bersama saudara/saudari **kandung atau sebapak**. (Saudara seibu terhijab kakek secara ijma'.)

## 8.1 Titik Khilaf Induk [R08-1] [R08-6] [R08-7]
> **KHILAF — Apakah kakek menghijab saudara kandung/sebapak?**
> - **Pendapat 1 — [SYF] (default)**: Zaid bin Tsabit, Ali; diikuti **Syafi'i, Malik, dan riwayat masyhur Ahmad**, Abu Yusuf, Muhammad. Dinukil eksplisit: *"وذهب إليه الشافعي ومالك وأحمد في المشهور عنه أنه لا يحجبهم"* (Syafi'i, Malik, dan riwayat masyhur Ahmad berpendapat kakek **tidak** menghijab saudara). **Saudara tetap mewarisi bersama kakek** dengan rincian 8.2–8.5 (madzhab Zaid).
> - **Pendapat 2 — Ibnu 'Utsaimin (rajih menurut beliau, bukan pendapat Syafi'i)**: Abu Bakr ash-Shiddiq, Abu Musa, Ibnu Abbas, dan sekitar 14 sahabat; Abu Hanifah; pilihan Ibnu Taimiyah dan Ibnul Qayyim. **Kakek = ayah**: menghijab semua saudara secara mutlak. Seluruh rincian muqasamah, mu'addah, akdariyyah **tidak diperlukan** menurut pendapat ini. Disediakan sebagai opsi, bukan default.
>
> **Aturan sistem**: sistem hanya memakai [SYF] → jalankan 8.2–8.5. Pendapat 2 dicatat sebagai perbandingan, tidak diimplementasikan.

Dalil pendapat 2 (ringkas, untuk pembanding): kakek disebut "ayah" dalam Al-Qur'an (مِّلَّةَ أَبِيكُمْ إِبْرَاهِيمَ); ia menghijab saudara seibu secara ijma', maka menurut pendapat ini ia lebih utama menghijab saudara kandung; hadits «فما بقي فلأولى رجل ذكر» dan kakek lebih dekat (jihah ubuwwah).

## 8.2 [SYF]: Kakek Bersama Saudara Tanpa Ashabul Furudh [R08-2]
Kakek mengambil **yang terbaik** dari:
- **(a) Muqasamah**: kakek dihitung sebagai satu saudara lk (saudari = setengah).
- **(b) 1/3 dari seluruh harta**, sisanya untuk saudara (2:1).

**Kaidah cepat** (hitung "unit": saudara lk = 2, saudari = 1; kakek = 2):
| Jumlah unit saudara | Terbaik untuk kakek |
|---------------------|---------------------|
| < 4 (1 saudara lk; 1–3 saudari; 1 saudara lk + 1 saudari) | Muqasamah |
| = 4 (2 saudara lk; 1 lk + 2 pr; 4 pr) | Sama (pilih muqasamah secara default) |
| > 4 | 1/3 |

## 8.3 [SYF]: Kakek Bersama Saudara dan Ashabul Furudh [R08-3]
Setelah furudh diberikan, kakek mengambil **yang terbaik** dari:
- **(a) Muqasamah** atas sisa,
- **(b) 1/3 sisa**,
- **(c) 1/6 dari seluruh harta**.

Ketentuan:
- Jika sisa setelah furudh **≤ 1/6** → kakek mendapat **1/6** (dengan 'aul bila perlu) dan **saudara gugur**, kecuali dalam al-Akdariyyah.
  - Sisa = 1/6 → kakek 1/6, saudara gugur.
  - Sisa < 1/6 → 'aul untuk kakek 1/6, saudara gugur.
  - Tidak ada sisa → 'aul untuk kakek 1/6, saudara gugur.
- Kaidah praktis: jika furudh > 1/2, 1/3 sisa tidak mungkin lebih baik dari 1/6; jika furudh < 1/2, 1/6 tidak mungkin terbaik; jika tepat 1/2, 1/3 sisa = 1/6.

**Contoh**: istri, kakek, 3 saudara lk kandung. Ashl 4 (istri 1, sisa 3).
- Muqasamah: 3/4 ÷ 4 kepala = 3/16.
- 1/3 sisa: 1/4 = 4/16. ✓
- 1/6: 2.67/16.
→ Kakek 1/3 sisa. Tashih 12: istri 3, kakek 3, saudara 6 (masing-masing 2).

## 8.4 [SYF]: Al-Mu'addah [R08-4]
1. Saudara **kandung** "menghitungkan" saudara **sebapak** bersama mereka terhadap kakek untuk memperkecil bagian kakek.
2. Setelah bagian kakek ditetapkan, saudara sebapak **tidak mendapat apa-apa**; bagiannya **dikembalikan** kepada saudara kandung.
3. **Pengecualian**: jika saudara kandung hanya **satu saudari**, ia mengambil sampai **1/2** penuh; jika masih ada sisa → untuk saudara sebapak.

Contoh: kakek, saudara lk kandung, saudara lk sebapak → muqasamah 3 kepala: kakek 1/3, kandung 1/3 + 1/3 dari sebapak = 2/3, sebapak 0.

## 8.5 [SYF]: Al-Masalah al-Akdariyyah [R08-5]
**Pola**: suami, ibu, kakek, **satu saudari** kandung atau sebapak.
**Langkah**:
1. Ashl 6: suami 1/2 = 3, ibu 1/3 = 2, kakek 1/6 = 1, saudari 1/2 = 3 → **'aul ke 9**.
2. Gabungkan bagian kakek dan saudari: 1 + 3 = **4**, lalu dibagi **2:1** (3 bagian) → tidak habis → tashih 9 × 3 = **27**.
3. Hasil: **suami 9, ibu 6, kakek 8, saudari 4**.

Alasan: saudari tidak boleh mendapat fardh lebih besar dari kakek (yang mengashabahkannya), tetapi juga tidak boleh gugur karena sisa habis; maka diberi fardh lalu dikembalikan ke muqasamah.

**Akdariyyah batal jika** pola berubah: suami diganti istri, ibu diganti nenek, saudari berjumlah 2+, atau ada saudara lk. Dalam kondisi itu kembali ke kaidah 8.3.

## 8.6 Algoritma Engine (Mode [SYF]) [KH]
```
if ada AYAH: saudara gugur (ijma')
elif ada JADD dan saudara kandung/sebapak:
    if pola == AKDARIYYAH: terapkan 8.5
    hitung furudh selain kakek dan saudara (setelah hajb biasa)
    sisa = 1 - furudh
    if tidak ada furudh:
        kakek = max(muqasamah, 1/3)
    else:
        if sisa <= 1/6: kakek = 1/6 (aul jika perlu); saudara = 0
        else: kakek = max(muqasamah(sisa), sisa/3, 1/6)
    terapkan mu'addah jika ada kandung + sebapak
    saudari tunggal kandung: klaim hingga 1/2 dari bagian saudara (8.4 no.3)
```
