# 15. Glosarium

| Istilah | Arab | Makna |
|--------|------|------|
| Irts | الإرث | Perpindahan kepemilikan dari mayit kepada ahli warisnya |
| Tirkah | التركة | Harta dan hak yang ditinggalkan mayit |
| Muwarrits | المورِّث | Pewaris (mayit) |
| Warits | الوارث | Ahli waris |
| Fardh | الفرض | Bagian yang ditentukan syariat (1/2, 1/4, dst.) |
| Ashabul furudh | أصحاب الفروض | Ahli waris yang mewarisi dengan fardh |
| Ta'shib / 'Ashabah | التعصيب / العصبة | Mewarisi tanpa bagian tertentu (seluruh atau sisa) |
| Bi nafsihi | العصبة بالنفس | Ashabah karena diri sendiri |
| Bil ghair | العصبة بالغير | Perempuan yang menjadi ashabah karena laki-laki sederajat |
| Ma'al ghair | العصبة مع الغير | Saudari yang menjadi ashabah bersama anak/cucu pr |
| Far'u warits | الفرع الوارث | Anak dan cucu dari anak lk, dst. |
| Ashl warits | الأصل الوارث | Ayah, kakek, ibu, nenek yang mewarisi |
| Hawasyi | الحواشي | Saudara, anak saudara, paman, anak paman |
| Kalalah | الكلالة | Mayit tanpa anak dan tanpa ayah (ushul lk) |
| Hajb | الحجب | Penghalangan ahli waris oleh ahli waris lain |
| Hajb hirman | حجب الحرمان | Gugur seluruh bagian |
| Hajb nuqshan | حجب النقصان | Berkurang ke bagian yang lebih kecil |
| Mani' | المانع | Sifat penghalang waris (riqq, qatl, beda agama) |
| Jadd shahih | الجد الصحيح | Kakek tanpa perempuan di antara dia dan mayit |
| Jadd fasid | الجد الفاسد | Kakek dengan perempuan di antaranya (dzawil arham) |
| Jaddah shahihah | الجدة الصحيحة | Nenek yang tidak diselingi kakek fasid |
| Ashlul mas'alah | أصل المسألة | Penyebut bersama terkecil |
| 'Aul | العول | Kelebihan jumlah saham atas ashl |
| Radd | الرد | Pengembalian sisa kepada ashabul furudh |
| 'Adilah | العادلة | Masalah yang saham = ashl |
| Tashih | التصحيح | Bilangan terkecil agar setiap bagian bulat |
| Inkisar | الانكسار | Saham kelompok tidak habis dibagi anggotanya |
| Juz' as-sahm | جزء السهم | Pengali tashih |
| Tamatsul/Tadakhul/Tawafuq/Tabayun | التماثل/التداخل/التوافق/التباين | Empat relasi bilangan |
| Wafq | الوفق | Hasil bagi bilangan dengan FPB |
| Munasakhat | المناسخات | Ahli waris wafat sebelum tirkah dibagi |
| Jami'ah | الجامعة | Tashih gabungan dalam munasakhat |
| Takharuj | التخارج | Ahli waris keluar dengan imbalan berdasarkan kesepakatan |
| Muqasamah | المقاسمة | Kakek berbagi sebagai saudara lk |
| Mu'addah | المعادّة | Saudara kandung menghitungkan saudara sebapak terhadap kakek |
| Akdariyyah | الأكدرية | Suami, ibu, kakek, saudari |
| Musyarrakah/Himariyyah | المشرّكة/الحمارية | Suami, ibu/nenek, 2+ seibu, saudara kandung |
| 'Umariyyatain | العمريتان | Pasangan + ayah + ibu |
| Minbariyyah | المنبرية | Istri, ayah, ibu, 2 anak pr (24 → 27) |
| Qarib mubarak | القريب المبارك | Mu'ashshib yang tanpa dia perempuan itu tidak mendapat apa-apa |
| Qarib masy'um | القريب المشؤوم | Mu'ashshib yang tanpa dia perempuan itu mendapat fardh |
| Takmilah tsulutsain | تكملة الثلثين | 1/6 penyempurna 2/3 |
| Mafqud | المفقود | Orang hilang tanpa kabar |
| Haml | الحمل | Janin |
| Khuntsa musykil | الخنثى المشكل | Orang dengan status jenis kelamin tidak jelas |
| Mauquf | الموقوف | Bagian yang ditangguhkan |
| Dzawil arham | ذوو الأرحام | Kerabat tanpa fardh dan bukan ashabah |
| Tanzil | التنزيل | Menempatkan dzawil arham di posisi perantaranya |
| Wala' | الولاء | Kekerabatan hukmi karena memerdekakan budak |
| Mu'tiq | المعتِق | Yang memerdekakan |
| Tilad | التلاد | Harta asli (bukan hasil warisan dari yang wafat bersamanya) |
