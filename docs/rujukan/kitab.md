# Sumber Baca Kitab

Tautan dan berkas untuk tombol "Baca kitab" di halaman Rujukan. Judul harus sama dengan kolom Judul di KB bab 17.2.

- **Tautan**: halaman kitab di situs resmi/legal (dibuka di tab baru). Kosong = tombol nonaktif.
- **PDF**: nama berkas di `apps/web/public/kitab/`, hanya untuk berkas yang lisensinya jelas boleh diunggah.
  Kosong = tidak ada tampilan di dalam aplikasi.
